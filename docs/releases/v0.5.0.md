# v0.5.0 — the control room leads with the next step

`v0.5.0` redesigns the local browser workspace around one question: what should
I do next. It changes no artifact schema, provenance rule, gate condition,
exit code, or terminal-only human-decision boundary — the same run directory
reads the same way; the browser just explains it in plain sentences first.

## What changed

- The next action is the first thing on screen, carrying its exact terminal
  command with a copy control. A human decision announces itself as "your
  turn"; the browser still records nothing — the command is the handoff.
- One derived sentence under the progress seal says whether anything actually
  needs attention. It counts only states that always mean trouble (stale or
  invalid files, exhausted revision budgets), so a fresh study reads calm.
- Stage bands on the study map fold behind plain sentences — "All 5 steps
  recorded.", "Not reached yet — earlier steps come first." — composed from
  counts. Exact state words stay on every row, and the spine remains derived
  from `graph.yaml`; no node identifier enters the browser source.
- Files group into three folds: needs attention (open whenever non-empty),
  waiting to be written, and recorded and matching.
- A card on the overview links to the reference architecture drawing, which
  keeps opening as its own read-only document with "you are here" marked at
  serve time. The plate is still never embedded in a study screen.

## Install this exact release

```bash
uv tool install rgraph==0.5.0
rgraph demo --scenario 1
```

Or run it without a persistent install:

```bash
uvx --isolated --from rgraph==0.5.0 rgraph demo --scenario 1
```

## Compatibility and limits

- Python 3.11, 3.12, and 3.13 remain supported.
- Existing run directories require no migration.
- Mechanical checks establish only their declared conditions. Scientific
  correctness was not determined.
